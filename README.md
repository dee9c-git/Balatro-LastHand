# LastHand
#### Shows that this will be your last hand.
<img alt="banner" height="250" src="/assets/thumbnail.jpg" />
</div>

## Features
- Provides simple text edits on the Play/Discard buttons for the scernarios:
    - First Hand
    - Last Hand
    - First Discard
- Supports just en-US for now.
- Made for Vanilla Balatro

## Install
1. Install the [Balatro Mod Manager](https://github.com/skyline69/balatro-mod-manager)
2. Install Steamodded using the mod manager.
3. Search for "LastHand" in the mod manager and install the mod!
